# feishuCode2Img

飞书 / Lark 代码块一键复制为图片的 Tampermonkey 用户脚本。

脚本会在飞书文档代码块右下角添加 `📸 图片` 按钮。点击后会将当前代码块渲染为 PNG 图片并写入系统剪贴板，适合把代码片段快速粘贴到聊天、文档或演示材料中。

## 功能特性

- 支持飞书中国站 `feishu.cn` 和 Lark 国际站 `larksuite.com`
- 自动识别页面中的代码块，并为每个代码块添加图片复制按钮
- 复制时保留代码块标题区域，隐藏复制按钮、工具栏、拖拽控件等干扰元素
- 自动展开代码块内容，尽量避免截图时出现内部滚动条或内容裁切
- 复制结果直接写入剪贴板，无需手动下载图片
- 页面内容动态变化时自动重新扫描，适配飞书文档的异步渲染

## 安装方式

1. 在浏览器中安装 Tampermonkey 扩展。
2. 打开 Tampermonkey 管理面板，创建新脚本。
3. 将 [feishuCode2Img.js](./feishuCode2Img.js) 的完整内容粘贴进去并保存。
4. 打开或刷新飞书 / Lark 文档页面。
5. 在代码块右下角点击 `📸 图片`，图片会被复制到剪贴板。

## 使用要求

- 推荐使用最新版 Chrome、Edge 或其他 Chromium 内核浏览器。
- 浏览器需要支持 `navigator.clipboard.write` 和 `ClipboardItem`。
- 首次点击按钮时，脚本会从 unpkg 加载 `html-to-image@1.11.11`。
- 当前页面需要允许剪贴板写入权限；如果浏览器弹出授权提示，请选择允许。

## 工作原理

脚本通过 Tampermonkey 注入到飞书 / Lark 页面中，扫描代码块 DOM，追加一个独立的图片复制按钮。点击按钮后会：

1. 加载 `html-to-image` 渲染库。
2. 临时隐藏工具栏、复制按钮和拖拽控件。
3. 临时展开代码块尺寸，计算完整截图宽高。
4. 将代码块 DOM 渲染为 PNG Blob。
5. 使用 Clipboard API 将图片写入剪贴板。
6. 恢复页面原始样式。

## 常见问题

### 点击后提示“当前浏览器不支持图片写入剪贴板”

当前浏览器或页面环境不支持图片写入 Clipboard API。建议更换最新版 Chrome 或 Edge 后重试。

### 点击后一直失败或没有反应

可以按以下顺序检查：

1. 当前页面是否为 `feishu.cn` 或 `larksuite.com` 域名。
2. Tampermonkey 中脚本是否已启用。
3. 浏览器是否阻止了剪贴板权限。
4. 网络是否能访问 `https://unpkg.com/html-to-image@1.11.11/dist/html-to-image.js`。
5. 打开开发者工具 Console，查看是否有脚本错误日志。

### 复制出的图片内容被裁切

脚本会尽量展开飞书代码块内部容器，但飞书页面结构可能随版本变化。如果出现裁切，可以刷新页面后重试；若仍然存在，请提交 issue 并附上页面结构或截图信息。

## 隐私说明

脚本仅在浏览器本地运行，不会主动上传文档内容。图片生成过程在当前页面完成；第三方依赖仅用于加载 `html-to-image` 前端库。
